## Open (not agreed: ask the user before working on them)
Questions waiting for answers: `docs/questionnaire.md`.
- Dev tool UI only type-checked/built, never rendered in a browser: the user checks it (2026-10-24).
- Locality-aware routing (asked by the user 2026-10-24, design not agreed): nodes get a region/place; when forwarding, the set cover picks the owners nearest to the sender first (today: node owning most matched transitions first, random ties). Decisions open: what "near" means (same region only, region hierarchy, coordinates, measured latency); where the region is declared and synced (node option, certificate, raft log with membership); precedence against the fewest-nodes rule; fallback when the nearest owner is unreachable (re-cover by distance); clients' region.
- Remote calls close containers held open by another holder (found in econsim 2026-10-26, user: note it, fix later in asm): `callContainer`/`sendToContainer` (node.go) pass `withCloseAfter()` also when the call joins a container a local caller opened with `StartContainer` (econsim's driver, multi-step acts); the container closes when idle between two of the holder's events, and its next `Event` returns `ErrContainerClosed`. Idea: close after the call only if the call opened the container. econsim works around it (resends the step to a new container, ~21 per 30s with 4 regions).
